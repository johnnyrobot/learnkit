# Contributor Code of Conduct

LearnKit is a community project. We are committed to respectful, inclusive collaboration.

Everyone should feel safe to participate, including people from all backgrounds and neurotypes.

## Expected behavior

- Be respectful in comments, reviews, and discussion.
- Critique ideas, not people.
- Use clear, evidence-oriented language.

## Unacceptable behavior

- Harassment, hate, or personal attacks.
- Dismissing contributors without cause.
- Spam, abuse, or leaking private information.

## Reporting

If you witness problematic behavior, please open a private issue or contact the maintainer
directly so we can review and resolve it promptly.
